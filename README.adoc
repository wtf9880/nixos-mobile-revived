*Mobile NixOS* is a superset on top of link:https://nixos.org/nixos/[NixOS Linux],
link:https://nixos.org/nixpkgs/[Nixpkgs] and link:https://nixos.org/nix/[Nix],
aiming to abstract away the differences between _mobile_ devices.

In four words: _“NixOS, on your phone”_.

This repository is a fork of
link:https://github.com/mobile-nixos/mobile-nixos[upstream Mobile NixOS].

== Continuous Integration

There are no published build artifacts at the moment. The GitHub Actions
workflows check that:

 * all Nix files parse (`.ci/parse-all.sh`);
 * every device evaluates (`.ci/quick-eval.sh`);
 * the generated kernel configuration is up-to-date (`bin/kernel-normalize-all --only-check`);
 * the documentation builds (`.github/workflows/docs.yml`).

The `Instantiation` job (`bin/hydra-eval`) is currently disabled.

== Development

This repository is a flake, with the Nixpkgs pin recorded in `flake.lock`.

 * `nix develop` — start a shell with the tools useful for porting devices;
 * `nix build .#docs` — build the documentation;
 * `nix-build ./default.nix --argstr device <identifier> -A outputs.default` —
   build a device without evaluating the flake.

The non-flake entry points (`default.nix`, `shell.nix`, and `pkgs.nix`) read the
same `flake.lock`, so they stay in sync with the flake.
